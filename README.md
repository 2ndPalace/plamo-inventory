# プラモ在庫管理（単体版）

ガンプラ本体と、塗料・デカールなどの資材を管理する在庫管理PWAです。
ビルド不要で、静的ファイルだけで動きます。GitHub Pages やローカルのWebサーバーにそのまま置いて使えます。

## 主な機能

- **ガンプラ本体の在庫**: グレード（HG / RG / MG / PG など）と製作状況（予約中 / 未組立 / 製作中 / 完成）を記録できます。製作状況で絞り込めるので、積みプラの確認に使えます。
- **プレミアムバンダイ・限定品**: ガンプラごとに販路（一般販売 / プレミアムバンダイ / イベント・店舗限定）を記録できます。予約中の品目には発送予定月を付けられます。販路で絞り込めて、「プレバン」での検索にも対応しています。
- **在庫一覧・絞り込み**:
  - 商品名・JAN・メーカー・品番・置き場で検索できます。
  - 種別（ガンプラ / 塗料 / デカール / その他）と在庫状態（在庫あり / 残りわずか / 不足 / 在庫なし）で絞り込めます。
  - 数量は大きな `−` / `＋` ボタンで増減します。
- **買い物リスト**: 所持数が目標数より少ない品目を自動で集め、足りない数を「あと n」で表示します。
- **JANコードでの登録・照合**:
  - カメラで読み取れます。手入力や、USB / Bluetooth のバーコードリーダー（Enterで確定）も使えます。
  - 照合は「自分の在庫 → UPCitemdb → ホビーサーチ用プロキシ」の順に行い、見つからなければ手動登録になります。経過は照合ログに表示されます。
  - ホビーサーチ・プレミアムバンダイ・Amazon・楽天市場・駿河屋の検索結果を開くリンクも出ます。
- **GitHub 同期とJSONバックアップ**:
  - 非公開のGitHubリポジトリにある `inventory.json` を読み書きします。別の端末から更新されていた場合は、競合として知らせます。
  - トークンなしで使う場合やバックアップには、JSONのエクスポート / インポートを使います。

## 画面の見方

- 一覧の各行は「札 | 名前・置き場 | − 数量 ＋」の順に並びます。札には、ガンプラはグレード、塗料などは品番が入ります。
- ガンプラの札は、塗り方で製作状況を表します。

  | 札の見た目 | 製作状況 |
  |---|---|
  | 破線の枠 | 予約中（まだ届いていない） |
  | 枠だけ | 未組立 |
  | 下に帯 | 製作中 |
  | ベタ塗り | 完成 |

- 札の右上の小さな印は販路です。`P` はプレミアムバンダイ、`限` はイベント・店舗限定を表します。
- 名前の部分をタップすると、編集フォームが開きます。削除は誤操作を防ぐため、編集フォームの中にだけあります。
- 札の左端の朱色の線と「あと n」は、補充が必要なことを示します。
- 配色・書体・レイアウトの決まりは `DESIGN_LOCK.md` にまとめています。

## スマホでのセットアップ

前提として、アプリを GitHub Pages で公開済みであるものとします（公開の手順は「GitHub Pages への置き方」を参照）。
データは、アプリとは別の非公開リポジトリに置いた `inventory.json` に保存します。

所要時間はおよそ10分です。手順3（トークンの発行）だけはPCで行うほうが楽ですが、スマホのブラウザでもできます。

### 1. アプリを開いて、ホーム画面に追加する

**iPhone（Safari）**

1. Safari で `https://<ユーザー名>.github.io/<コード用リポジトリ名>/` を開きます。
2. 画面下の共有ボタン（四角から上向きの矢印が出たアイコン）をタップします。
3. 「ホーム画面に追加」を選び、右上の「追加」をタップします。
4. 以降は、**ホーム画面のアイコンから開いてください。**

> **注意（iPhone）**: ホーム画面から開いたアプリと Safari のタブでは、保存場所が別々です。Safari で入れた設定やデータは、ホーム画面のアプリには引き継がれません。設定は、ホーム画面のアプリを開いてから入力してください。

**Android（Chrome）**

1. Chrome で同じURLを開きます。
2. 右上の︙メニューから「ホーム画面に追加」（または「アプリをインストール」）を選びます。
3. 以降は、ホーム画面のアイコンから開いてください。

### 2. カメラの使用を許可する

1. 下のナビの「JAN登録」を開き、「カメラで読み取る」をタップします。
2. カメラの使用を確認されたら「許可」を選びます。
3. 一度拒否した場合は、端末の設定から許可し直します。
   - iPhone: 設定 →（アプリ →）Safari → カメラ →「許可」
   - Android: Chrome の︙ → 設定 → サイトの設定 → カメラ

カメラは HTTPS のページでしか使えません。GitHub Pages のURLは HTTPS なので、そのまま使えます。

### 3. データ用のアクセストークンを発行する

アプリが非公開のデータ用リポジトリを読み書きするための鍵（Fine-grained Personal Access Token）を作ります。
GitHub の公式アプリではトークンを作れないので、ブラウザで github.com を開いてください。

1. https://github.com/settings/personal-access-tokens/new を開きます。
   - メニューからたどる場合は、右上のアイコン → Settings → Developer settings → Personal access tokens → Fine-grained tokens →「Generate new token」です。
   - スマホでは、ページ下部の「デスクトップ版」に切り替えると操作しやすくなります。
2. 次のように入力します。

   | 項目 | 入力する値 |
   |---|---|
   | Token name | `plamo-inventory-phone` など、どの端末用か分かる名前 |
   | Expiration | 有効期限。期限が来たら作り直す必要があります（90日程度を推奨） |
   | Repository access | 「Only select repositories」を選び、**データ用リポジトリだけ**を選択 |
   | Permissions → Repository permissions → Contents | **Read and write** |

3. 「Generate token」をタップし、表示された `github_pat_` で始まる文字列をコピーします。この文字列は**この画面でしか表示されません**。

端末ごとに別のトークンを作っておくと、スマホをなくしたときに、そのトークンだけを無効にできます。

### 4. アプリに同期先を設定する

1. ホーム画面からアプリを開き、下のナビの「設定」を開きます。
2. 「GitHub リポジトリ」に次の値を入力します。

   | 項目 | 入力する値 |
   |---|---|
   | Owner | GitHub のユーザー名 |
   | Repo | データ用リポジトリの名前（例: `plamo-inventory-data`） |
   | Branch | `main` |
   | Path | `inventory.json` |
   | Personal Access Token | 手順3でコピーした文字列を貼り付け |

3. 「設定を保存」をタップします。
4. 画面上部の「GitHubから読み込む」をタップします。「GitHubから読み込みました（n件）」と出れば完了です。

> **最初に必ず「GitHubから読み込む」を押してください。** 読み込まないうちに「GitHubへ保存」を押すと、競合エラーになります。

### 5. ふだんの使い方

- 在庫の変更は、まずスマホの中に保存されます。**GitHub への保存は自動では行われません。** 区切りのよいところで、設定タブの「GitHubへ保存」を押してください。
- PCや別のスマホでも使う場合は、使い始める前に「GitHubから読み込む」、使い終わったら「GitHubへ保存」を押します。
- 保存時に「競合が発生しました」と出たら、別の端末で先に保存されています。
  - 先に「GitHubから読み込む」を押してから、変更をやり直して保存します。
  - 手元の内容でGitHub側を上書きしてよい場合だけ、「強制上書き」を使います。**GitHub側の変更は失われます。**
- トークンの有効期限が切れると、読み込みと保存が失敗します。手順3で作り直し、設定タブで貼り替えてください。

### スマホでのトラブル対処

| 症状 | 対処 |
|---|---|
| 「カメラで読み取る」で何も映らない | カメラの許可（手順2）を確認します。読み取れない場合は、下の欄にJANを入力して「照合」を押します。 |
| 瓶や箱のバーコードを読み取れない | 明るい場所で、バーコードを画面の枠いっぱいに写します。曲面や光沢面は斜めから写すと読み取りやすくなります。 |
| 読み込みで「Bad credentials」と出る | トークンの貼り間違いか、期限切れです。トークンを作り直して貼り替えます。 |
| 読み込みで「Not Found」と出る | Owner / Repo / Path の綴りを確認します。トークンの Repository access にデータ用リポジトリが入っているかも確認します。 |
| データが消えた | iPhone では、Safari のタブとホーム画面のアプリで保存場所が別です（手順1の注意）。いつもと違う開き方をしていないか確認し、「GitHubから読み込む」で戻します。 |
| 更新したのに画面が古いまま | アプリを一度完全に閉じて開き直します。 |

## GitHub Pages への置き方

1. GitHub で、アプリ用の新しい**公開**リポジトリを作り、このフォルダのファイル一式（`index.html`、`style.css`、`app.js`、`manifest.webmanifest`、`sw.js` など）を push します。
2. リポジトリの **Settings → Pages** を開きます。
3. **Source** で `Deploy from a branch` を選び、ブランチを `main`、フォルダを `/ (root)` にして保存します。
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになります。

データ用には、別に**非公開**のリポジトリを作り、中身が次の `inventory.json` を1つだけ置いておきます。

```json
{
  "version": 1,
  "updatedAt": "2026-01-01T00:00:00.000Z",
  "items": []
}
```

在庫データは公開リポジトリに置かないでください。公開リポジトリのファイルは誰でも読めます。

## GitHub 同期の設定（PC）

設定する値は、スマホの手順3〜4と同じです。トークンは PC 用に別に発行することをおすすめします。

> **セキュリティ上の注意**: 入力したトークンは、そのブラウザの `localStorage`（`plamo-settings-v1`）にだけ保存されます。JSONエクスポートのファイルには含まれません。共有のPCでは使わないでください。

## Cloudflare Worker のデプロイ手順（任意）

国内のホビー商品をJANから自動で調べたい場合は、`worker/hobbysearch-worker.js` を Cloudflare Workers にデプロイします。

1. Cloudflare のダッシュボードにログインし、**Workers & Pages → Create → Create Worker** を開きます。
2. 好きな名前（例: `hobbysearch-proxy`）で Worker を作り、**Edit code** に `worker/hobbysearch-worker.js` の中身を貼り付けて **Deploy** します。
3. 発行されたURL（例: `https://hobbysearch-proxy.<subdomain>.workers.dev`）を、アプリの **設定 → ホビーサーチ用プロキシ URL** に入力して保存します。

## JAN照合の仕組みと限界

このアプリは「APIキーなしで動くこと」を優先しているため、JAN照合には次の制約があります。

1. **UPCitemdb 無料トライアルAPI**
   - キーなしで使えますが、1日の回数制限と、短時間に使いすぎたときの制限（HTTP 429）があります。
   - 海外のデータが中心なので、**日本の塗料・デカール・プレバン商品は見つからないことが多い**です。
   - ブラウザから直接呼ぶと、CORSエラーになる環境もあります。その場合は、照合ログに理由を出して次の段階へ進みます。
2. **ホビーサーチ用プロキシ（Cloudflare Worker）**
   - ホビーサーチ（`www.1999.co.jp`）の検索ページと商品ページのHTMLを取得し、JSON-LDなどから商品情報を取り出します。
   - **相手サイトのボット対策（WAF や Cloudflare のチャレンジなど）で、HTTP 403 などで拒否されることがあります。** そのときは Worker が HTTP 502 を返し、推測したデータは返しません。
   - 相手サイトのHTML構造が変わると、取り出せなくなることもあります。
3. **Webで確認のリンク**
   - 自動で調べられなかった場合は、ホビーサーチ・プレミアムバンダイ・Amazon・楽天市場・駿河屋の検索結果を新しいタブで開けます。目で確かめてから手入力してください。
   - プレミアムバンダイの商品は、店頭向けのJANデータベースに載っていないことがあります。見つからないときは、商品名で登録し、販路を「プレミアムバンダイ」にしてください。
4. **カメラでの読み取り**
   - カメラ（`getUserMedia`）は **HTTPS** のページ（または `localhost`）でしか使えません。
   - 暗い場所や、塗料瓶の曲面・光沢面ではピントが合わず、読み取れないことがあります。その場合は手入力の欄を使ってください。
